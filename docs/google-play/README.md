# АвтоВес Водитель в Google Play

Приложение ставится водителям из Google Play: обновления приходят сами, уведомления о заказах идут через
Google (Firebase Cloud Messaging), данные уходят на ваш сервер АвтоВес по домену.

Ключи, пароли и файлы Firebase в репозиторий **не кладутся** — только в секреты GitHub и на сервер.

## 1. Firebase (уведомления)

1. https://console.firebase.google.com → «Создать проект» (Google Analytics можно выключить).
2. В проекте: «Добавить приложение» → Android → имя пакета **`ru.avtoves.driver`** → скачать `google-services.json`.
3. Настройки проекта → «Сервисные аккаунты» → «Создать закрытый ключ» → скачается JSON-файл.
   В кабинете администратора: «Подключения» → «Приложение водителя» → **«Загрузить ключ Firebase»** → выбрать
   этот файл. Сервер сразу проверит ключ у Google; строка «Уведомления через Google» станет зелёной.
   Кнопка **«Проверить уведомление»** отправит пробное уведомление на телефон выбранного водителя.

## 2. GitHub: секреты и адрес сервера

Репозиторий → Settings → Secrets and variables → Actions:

| Что | Вкладка | Имя | Значение |
|---|---|---|---|
| Ключ подписи | Secrets | `ANDROID_KEYSTORE_B64` | из файла с ключом подписи |
| Пароль ключа | Secrets | `ANDROID_KEYSTORE_PASSWORD` | из того же файла |
| Firebase | Secrets | `GOOGLE_SERVICES_JSON` | всё содержимое `google-services.json` |
| Адрес сервера | Variables | `AVTOVES_SERVER` | ваш домен, например `ves.example.ru` |

Ключ подписи храните в надёжном месте: без него нельзя выпустить обновление приложения.

## 3. Сборка

Actions → «АвтоВес Водитель — APK и Google Play» → Run workflow (ветка `v2`).
Когда заданы ключ подписи и `GOOGLE_SERVICES_JSON`, в результатах сборки появится
**AvtoVes-Voditel-GooglePlay-aab** — файл `app-release.aab` для Google Play. Номер версии растёт сам.

## 4. Google Play Console

**Создать приложение:** название «АвтоВес Водитель», язык русский, приложение, бесплатное.

**Подписание:** при первой загрузке согласитесь на «Подписание приложений в Google Play»; наш ключ станет ключом загрузки.

**Страница в магазине** (Продвижение → Основная страница):

- Краткое описание (до 80 знаков):
  `Заказы, взвешивание на весах базы и учёт выгрузок газа для водителей`
- Полное описание:

  > Рабочее приложение для водителей газовозов компании, которая использует систему АвтоВес.
  >
  > • Заказы от логиста с уведомлениями и порядком объезда
  > • Звонок клиенту одной кнопкой, маршрут в Яндекс Навигаторе или Яндекс Картах
  > • Взвешивание на весах базы: «Приехал» и «Уехал» с выбором тягача и полуприцепа
  > • Запись выгрузок: клиент, литры, оплата для частных лиц, комментарий
  > • Остаток газа в цистерне по весам и итоги за день
  > • Работа без связи: записи отправятся, когда появится интернет
  >
  > Вход по логину и паролю, которые выдаёт логист. Самостоятельная регистрация не предусмотрена.

- Значок 512×512: `icon-512.png`; графический баннер 1024×500: `feature-1024x500.png`;
  скриншоты телефона: `1-zakazy.png`, `4-zvonok-marshrut.png`, `2-vzveshivanie.png`, `3-vygruzka.png` (из этой папки).
- Категория: «Бизнес» (или «Автомобили и транспорт»). Почта для связи — рабочая почта компании.

**Содержание приложения** (Политика → Содержание приложения):

- Политика конфиденциальности: `https://ВАШ-ДОМЕН/privacy`. Название компании и контакт для вопросов
  укажите в кабинете: «Подключения» → «Приложение водителя» → «Изменить сведения».
- Доступ к приложению: «Часть функций доступна только после входа» → дайте проверяющему Google
  отдельный тестовый логин водителя (заведите в кабинете водителя «Проверка Google») и адрес сервера.
  Сервер должен быть доступен из интернета по домену.
- Реклама: нет. Целевая аудитория: 18+. Возрастной рейтинг: анкета, везде «нет».
- Новостное приложение: нет. Медицинское / финансовое: нет. Госприложение: нет.

**Безопасность данных** (Data safety):

| Вопрос | Ответ |
|---|---|
| Собирает или передаёт данные | Да |
| Шифруются при передаче | Да (HTTPS) |
| Можно запросить удаление | Да, через контакт из политики конфиденциальности |
| Личные данные → Имя | Собирается, не передаётся; функции приложения; обязательно |
| Действия в приложении → Другой пользовательский контент (выгрузки, комментарии) | Собирается, не передаётся; функции приложения |
| Идентификаторы устройства или другие (токен уведомлений) | Собирается, не передаётся; функции приложения |
| Местоположение, контакты, фото, файлы, финансы, здоровье | Не собираются |

Сервис уведомлений Google считается обработчиком данных, а не передачей третьим лицам.

## 5. Выпуск для своих водителей

Тестирование → **Внутреннее тестирование** → создать список тестировщиков (Google-почты водителей, до 100) →
«Создать выпуск» → загрузить `app-release.aab` → сохранить и выпустить. Водители получают ссылку,
нажимают «Стать тестировщиком» и ставят приложение из Google Play; дальше обновления приходят как обычно.

Для открытой публикации личному аккаунту разработчика Google обычно требует сначала закрытое
тестирование (не меньше 12 тестировщиков в течение 14 дней) — условия смотрите в своей консоли.

## 6. Обновления

Изменили приложение → сборка на GitHub → новый `app-release.aab` → в том же треке «Создать выпуск» →
загрузить. Телефоны водителей обновят приложение сами.
